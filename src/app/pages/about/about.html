Film Collection

A curated catalog of must-watch films, built with Angular Signals.

🎬

About the project

Film Collection is a single-page application for browsing a handpicked catalog of classic and modern films. Search by title, mark favorites, and explore full details for every movie.

⚙

Tech stack

  • Angular 20+ — standalone components
  • Angular Signals — no RxJS
  • TypeScript strict mode
  • Plain CSS
